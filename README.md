# Public PD API

The API to be used with all PD modules.

## Usage

This is a machine readable API definition. Use https://editor.swagger.io/ to view it (no account needed) or generate code. Alternatively, [OpenAPI Generator](https://github.com/openapitools/openapi-generator) can be used to generate code.

## Module names

The API contains "ABCD" in several places. "ABCD" is to be replaced with module names like "Wortgenau" or "HastDuWorte". I.e.: "https://server.net/api/tst_modules/ABCD/result/session/list" turns into "https://server.net/api/tst_modules/Wortgenau/result/session/list". If you need a module name, feel free to contact us.

## Example Code

We have example code using this API in several programming languages. Talk to us if you need examples.
